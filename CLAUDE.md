# Coding Guidelines

Always prefer:

Semantic HTML

Small components

Composition

Reusable code

Readable CSS

Avoid:

Inline styles

Duplicated components

Overengineering

Large JavaScript files

Global variables

---

# CSS Philosophy

Use CSS Variables.

Use Grid.

Use Flexbox.

Prefer logical properties.

Avoid !important.

Avoid deep selectors.

Avoid unnecessary nesting.
