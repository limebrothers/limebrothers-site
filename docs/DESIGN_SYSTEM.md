# Design System

## Vision

The visual identity should communicate engineering excellence.

The experience should feel closer to Stripe, Vercel or Linear than to a traditional consultancy website.

---

Modern

Technical

# Design Principles

- Large typography
- Generous whitespace
- Few colors
- Few visual effects
- Elegant animations
- Content first
